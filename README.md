# 今天吃什么 🍜

一个纯前端的「下一顿吃什么」决策助手：记录爱吃的、爱做的、踩雷的，结合家里库存和特殊时期忌口（生病 / 月经期 / 用药期），给出 3 个推荐候选，并解释为什么推荐。

在线版：https://windmillsymphony.github.io/what2eat/ （安卓 Chrome 打开 → 菜单 → 安装应用）

## 运行方式

无需安装任何东西，三选一：

1. **直接双击打开** `index.html`（推荐桌面 Chrome / Edge / Firefox）
2. **本地服务器**（手机访问、Safari 必须用这种方式）：
   ```bash
   cd what2eat
   python3 -m http.server 8000
   ```
   然后手机与电脑连同一 WiFi，浏览器打开 `http://<电脑IP>:8000`
3. **安卓装成 App（PWA）**：把整个目录部署到任意 HTTPS 静态托管（免费的有 GitHub Pages / Cloudflare Pages / Netlify / Vercel），手机 Chrome 打开网址 → 菜单 → **「安装应用」/「添加到主屏幕」**，即可像原生 App 一样：桌面图标、全屏无地址栏、离线可用。

> ⚠️ Safari 对 `file://` 下的 localStorage 支持不稳定，Safari 用户请用方式 2。
> ⚠️ 安卓 Chrome 只在 HTTPS 或 localhost 下提供「安装应用」；局域网 IP（`http://192.168.x.x`）只能「添加到主屏幕」做书签。
> ⚠️ 换域名/换部署方式后数据不互通（localStorage 按域名隔离），用「数据备份 → 导出 / 导入」迁移一次即可。

## 功能

- 🎲 **推荐**：硬约束过滤（过敏 / 讨厌食材 / 忌口标签 / 辣度上限 / 踩雷拉黑 / 特殊时期）→ 软偏好打分（评分、爱吃、近期吃过降权、时间匹配、库存匹配、身体反馈惩罚）→ 3 个候选 + 换一批去重。每张卡片带推荐理由，底部可查看「被排除的菜」及原因
- 🍜 **菜品库**：外卖 / 自制、口味 5 维度（辣度 / 咸淡 / 甜度 / 酸度 / 口感 / 温度）、标签、食材、烹饪时间、评分、爱吃标记、拉黑 / 归档
- 🧺 **库存**：登记家里食材，推荐时「家里食材齐全」是最大加分项；记录用餐时可顺手扣减库存
- 🌡️ **特殊时期**：感冒 / 肠胃炎 / 月经期 / 用药期四个模板 + 自定义规则，规则快照可编辑，多时期规则自动叠加
- 💣 **踩雷记录**：哪家店哪道菜出了什么问题；「拉黑」级硬过滤、「提醒」级在卡片上标注
- 📅 **用餐历史**：吃完后评分 + 身体反馈（胀气 / 上火 / 过敏…），连续 2 次过敏自动硬拦截
- 💾 **数据备份**：全部数据存本机浏览器 localStorage，支持 JSON 导出 / 导入（跨设备同步、防丢失）

## 技术说明

- 原生 HTML / CSS / JS，无框架、无构建、无后端，全局 `W2E` 命名空间
- PWA：`manifest.webmanifest` + `sw.js`（网络优先 + 缓存兜底，离线可用；改代码后记得把 `sw.js` 里 `CACHE` 版本号 +1）
- 数据层：`js/storage.js`（单 key 整库 + 版本迁移，唯一 schema 定义处）
- 推荐算法：`js/recommend.js`（纯函数，可在 DevTools console 直接调试）：
  ```js
  W2E.rec.recommend(W2E.db.getState(), { availableTimeMin: 30 }).batch
  ```
- 演示数据：我的 → 数据备份 →「载入演示数据」，或 console 执行 `W2E.db.seedDemoData()`
